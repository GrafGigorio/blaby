## 🎯 Рекомендации:

### Для большинства задач достаточно:
1. ✅ Context7 - документация
2. ✅ Filesystem - файлы
3. ✅ Memory - память
4. ✅ Sequential Thinking - планирование
5. ✅ Brave Search - поиск

### Playwright vs Puppeteer:
- Используйте **Playwright** (стабильнее)
- Отключите **Puppeteer** если возникают таймауты

### Git альтернатива:
Continue уже имеет встроенный `diff` провайдер:
```yaml
context:
  - provider: diff  # Автоматически включает git изменения
```

### Docker альтернатива:
Используйте Bash команды напрямую:
```
docker ps
docker logs container_name
docker exec -it container_name bash
```

## 🔧 Устранение проблем:

### Если MCP сервер не подключается:

1. **Проверьте Node.js:**
   ```bash
   node --version  # Должна быть >= 18
   npx --version
   ```

2. **Очистите кэш npx:**
   ```bash
   rm -rf ~/.npm/_npx
   npm cache clean --force
   ```

3. **Проверьте существование пакета:**
   ```bash
   npm view @modelcontextprotocol/server-NAME version
   ```

4. **Посмотрите логи Continue:**
   - VS Code → Developer → Show Logs → Continue
