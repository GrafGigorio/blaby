# 🔀 LLM Routing - Полное руководство

## Что такое LLM Routing?

**LLM Routing** - это интеллектуальная система, которая:

1. **Анализирует** ваш запрос (тип, сложность, контекст)
2. **Выбирает** оптимальную модель для выполнения
3. **Готовит** специализированный промпт
4. **Координирует** работу нескольких моделей при необходимости

---

- ✅ Оптимизирует **промпт** под задачу

**Результат:**
- 🚀 Быстрее выполнение
- 💎 Лучше качество
- 🎯 Оптимальное использование ресурсов

## 🏗️ Архитектура системы

### 1. Встроенный роутинг в Continue (уже работает!)

Continue уже использует **простой роутинг** через роли:

```yaml
models:
  - name: 🤖 Agent (Mistral Small)
    roles:
      - agent  # ← Для задач с MCP инструментами
      - plan   # ← Для планирования

  - name: ⚡ Fast (Qwen3 30B)
    roles:
      - chat   # ← Для быстрых вопросов
      - edit   # ← Для редактирования
```

**Continue автоматически:**
- Использует модели с ролью `agent` для Agent режима
- Использует модели с ролью `chat` для обычного Chat
- Переключается между моделями при смене режима

### 2. Продвинутый роутер (создан для вас!)

**Местоположение:** `.continue/router-system/`

**Возможности:**
- Анализ типа задачи (11 типов)
- Оценка сложности (4 уровня)
- Определение необходимости MCP
- Оптимизация промптов
- Объяснение решений

## 🎓 Best Practices

### 1. Явно указывайте контекст

❌ Плохо:
```
Исправь код
```

✅ Хорошо:
```
Исправь эту функцию валидации email:
она падает с TypeError при передаче None
```

### 2. Используйте технические термины

Роутер лучше понимает:
- `"async функцию"` вместо `"асинхронный код"`
- `"pytest тесты"` вместо `"проверки"`
- `"SOLID принципы"` вместо `"хорошие практики"`

### 3. Указывайте инструменты

Если хотите MCP:
```
Используя Git покажи...
Через Filesystem найди...
С помощью Docker проверь...
```

### 4. Комбинируйте задачи

Для сложных workflow:
```
1. Найди файлы с классом APIClient (Filesystem MCP)
2. Проанализируй их историю (Git MCP)
3. Создай план рефакторинга (Sequential Thinking MCP)
4. Предложи улучшения кода (Qwen3-Coder)
```

## ❓ FAQ

### Q: Роутер работает автоматически в Continue?

**A:** Частично. Continue имеет базовый роутинг через роли (`agent`, `chat`).
Продвинутый роутер - это отдельная утилита для анализа и рекомендаций.

### Q: Нужно ли вручную переключать модели?

**A:** Да, Continue не переключает модели автоматически.
Но роутер подсказывает какую модель лучше использовать.

### Q: Зачем роутер если я могу сам выбрать?

**A:** Роутер:
- Оптимизирует промпт под задачу
- Напоминает о MCP инструментах
- Учит какую модель для чего лучше
- Экономит время на размышления

### Q: Можно ли добавить свою логику?

**A:** Да! Редактируйте `llm_router.py`:
- Добавьте новые типы задач
- Измените приоритеты моделей
- Кастомизируйте промпты
