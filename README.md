# Voice AI Assistant

> Локальный голосовой ассистент на базе Whisper, Ollama и Edge TTS

## Установка

```bash
pip install -r requirements.txt
./install_vosk.sh  # для потокового распознавания
```

## Пример

```bash
# Убедитесь, что Ollama запущен
ollama serve

# Запуск приложения
python main.py

# Откройте http://localhost:8000
```

## Компоненты

| Модуль | Технология | Описание |
|--------|------------|----------|
| STT | Whisper + Vosk | Распознавание речи |
| LLM | Ollama (gpt-oss:20b) | Генерация ответов |
| TTS | Edge TTS | Синтез речи |

## Использование

1. Нажмите кнопку микрофона или пробел
2. Говорите вопрос
3. Получите голосовой ответ
