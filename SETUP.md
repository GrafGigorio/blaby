# Инструкция по установке и запуску

## Быстрый старт

```bash
# Запустить приложение
./start.sh

# Или вручную:
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Системные требования

- Python 3.8+
- Ollama (должна быть установлена и запущена)
- Минимум 8GB RAM
- Доступ к микрофону в браузере

## Пошаговая установка

### 1. Установка зависимостей

```bash
# Создание виртуального окружения
python3 -m venv venv

# Активация
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# Установка пакетов
pip install --upgrade pip
pip install -r requirements.txt
```

### 2. Запуск Ollama

```bash
# Убедитесь что Ollama запущена
ollama serve

# В другом терминале проверьте модель
ollama list
```

### 3. Запуск приложения

```bash
python main.py
```

Откройте браузер: http://localhost:8000

## Использование

1. **Разрешите доступ к микрофону** в браузере
2. Нажмите кнопку "🎙️ Начать разговор" или клавишу **Пробел**
3. Говорите свой вопрос (до 10 секунд за раз)
4. Дождитесь ответа (будет автоматически воспроизведен)
5. После ответа микрофон снова активируется автоматически
6. Продолжайте разговор без необходимости нажимать кнопки
7. Нажмите "⏹️ Остановить разговор" или **Пробел** чтобы завершить

**Режим непрерывного диалога**: Общайтесь как с человеком - нажали раз, разговариваете, нажали снова чтобы закончить.

## Горячие клавиши

- **Пробел** - Начать/остановить разговор (непрерывный диалог)

## Настройка моделей

### Изменить размер Whisper модели

В файле `main.py` измените параметр:

```python
stt_module = STTModule(model_size="base")  # tiny, base, small, medium, large
```

- `tiny` - самая быстрая, но менее точная
- `base` - баланс скорости и качества (рекомендуется)
- `small` - более точная
- `medium`, `large` - максимальная точность, но медленные

### Изменить LLM модель

В файле `main.py`:

```python
llm_module = LLMModule(model_name="gpt-oss:20b")
```

Замените на любую модель из `ollama list`

### Настройка TTS

В файле `tts_module.py` можно изменить модель TTS.
По умолчанию используется `xtts_v2` (лучшее качество для русского языка).

## Возможные проблемы

### Ошибка загрузки TTS модели

Если `xtts_v2` не загружается, попробуйте:

```bash
pip install TTS --upgrade
```

Или измените модель в `tts_module.py`

### Ollama не найдена

Убедитесь что Ollama установлена:
```bash
ollama --version
```

Если нет, установите: https://ollama.ai

### Нет доступа к микрофону

- Используйте HTTPS или localhost
- Проверьте разрешения браузера
- Проверьте системные настройки конфиденциальности

### Медленная работа

- Используйте меньшую модель Whisper (`tiny` или `base`)
- Используйте меньшую LLM модель
- Убедитесь что другие приложения не загружают систему

## Оптимизация производительности

### Для CPU

```python
# В stt_module.py уже настроено:
fp16=False  # для CPU
```

### Для GPU (NVIDIA)

Убедитесь что установлен CUDA:
```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
```
