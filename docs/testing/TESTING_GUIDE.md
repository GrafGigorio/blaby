### Шаг 4: Проверка консоли

**В консоли браузера должно быть:**
- ✅ Минимум логов (только при ошибках)
- ❌ НЕ должно быть множества информационных логов (✅, 📦, 🔊, ℹ️)
- ✅ Могут быть критические ошибки с ❌ (если есть проблемы)

**Примеры допустимых логов:**
```
❌ Ошибка доступа к микрофону: [error message]
⚠️ WebSocket переподключение...
```

**НЕ должно быть:**
```
✅ AudioContext создан
📦 Отправка аудио чанка
🔊 Синтез: текст...
ℹ️ VAD активирован
```

## Известные проблемы и решения

### 1. Ошибка импорта модулей

**Проблема:** `ModuleNotFoundError: No module named 'config'`

**Решение:**
```bash
# Убедитесь что все __init__.py файлы созданы
touch api/__init__.py
touch core/__init__.py
touch utils/__init__.py
```

### 2. WebSocket не подключается

**Проблема:** `WebSocket connection failed`

**Решение:**
- Проверьте что сервер запущен
- Проверьте URL в `static/js/config.js`
- Проверьте firewall/antivirus

### 3. JavaScript модули не загружаются

**Проблема:** `Failed to load module script`

**Решение:**
- Убедитесь что используется `<script type="module">`
- Проверьте пути к файлам
- Проверьте MIME types сервера

### 4. Микрофон не работает

**Проблема:** `Permission denied` или `NotAllowedError`

**Решение:**
- Предоставьте разрешение на микрофон в браузере
- Используйте HTTPS или localhost
- Проверьте настройки приватности ОС
