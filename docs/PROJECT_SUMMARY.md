# Voice AI Assistant - Сводка проекта

## 🎯 Что сделано

Создан полнофункциональный локальный голосовой ассистент с веб-интерфейсом.

## 📦 Компоненты системы

### 1. **Speech-to-Text (STT)** - `stt_module.py`
- Использует OpenAI Whisper
- Поддержка русского и английского языков
- Настраиваемый размер модели (tiny/base/small/medium/large)
- Работает полностью локально

### 2. **Large Language Model (LLM)** - `llm_module.py`
- Интеграция с Ollama
- Использует модель `gpt-oss:20b`
- Сохраняет историю разговора (последние 10 сообщений)
- Возможность очистки истории

### 3. **Text-to-Speech (TTS)** - `tts_module.py`
- Использует Coqui TTS (XTTS v2)
- Качественный синтез русской речи
- Работает полностью локально без интернета
- Fallback на альтернативную модель при необходимости

### 4. **Backend API** - `main.py`
- FastAPI сервер
- Эндпоинты:
  - `POST /api/voice-chat` - основной голосовой чат
  - `GET /api/audio/{filename}` - получение аудио
  - `POST /api/clear-history` - очистка истории
- Автоматическая инициализация всех модулей при старте

### 5. **Web Interface** - `static/index.html`
- Современный градиентный дизайн
- Запись с микрофона через браузер
- Визуальные индикаторы статуса
- Автовоспроизведение ответов
- История разговора
- Горячая клавиша (Пробел) для управления записью
- Адаптивный дизайн

## 🚀 Как запустить

### Вариант 1: Автоматический запуск
```bash
./start.sh
```

### Вариант 2: Ручной запуск
```bash
# 1. Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Убедиться что Ollama запущена
ollama serve  # в отдельном терминале

# 4. Запустить приложение
python main.py
```

Откройте браузер: **http://localhost:8000**

## 🎤 Как использовать

1. Нажмите кнопку "🎙️ Начать разговор" или клавишу **Пробел**
2. Говорите свой вопрос на русском языке (до 10 секунд)
3. Система автоматически обработает запрос:
   - Распознает речь (STT)
   - Сгенерирует ответ (LLM)
   - Озвучит ответ (TTS)
4. Ответ автоматически воспроизведется
5. После ответа микрофон автоматически активируется снова
6. Продолжайте разговор - система будет циклически слушать и отвечать
7. Нажмите "⏹️ Остановить разговор" или **Пробел** чтобы завершить диалог

**Режим непрерывного диалога**: Нажимаете кнопку один раз, разговариваете как с человеком, нажимаете снова чтобы остановить.

## ⚡ Производительность

### Типичное время обработки (на CPU):
- **STT (Whisper base):** 2-5 секунд (для 5 сек аудио)
- **LLM (gpt-oss:20b):** 5-15 секунд (в зависимости от длины ответа)
- **TTS (XTTS v2):** 3-8 секунд (в зависимости от длины текста)

**Общее время:** 10-30 секунд от записи до ответа

### Оптимизация:
- Используйте Whisper `tiny` для более быстрого STT
- Используйте меньшую LLM модель (llama3.1:8b, qwen2.5:latest)
- Для GPU производительность увеличится в 3-5 раз

## 🐛 Известные ограничения

1. **Первая загрузка медленная** - модели скачиваются при первом запуске
2. **Требуется много RAM** - рекомендуется минимум 8GB
3. **XTTS v2 может быть медленной** на CPU
4. **Whisper требует numpy < 2.0** для стабильности
