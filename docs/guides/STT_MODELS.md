# Руководство по настройке моделей распознавания речи (STT)

В проекте используются две модели для распознавания речи:

## 1. Whisper (OpenAI) - Основное распознавание

Используется для обычного (не потокового) распознавания речи.

### Доступные модели

| Модель | Размер | Качество | Скорость | Рекомендация |
|--------|--------|----------|----------|--------------|
| tiny   | ~39 МБ | ⭐⭐     | ⚡⚡⚡⚡⚡ | Для слабых ПК |
| base   | ~74 МБ | ⭐⭐⭐   | ⚡⚡⚡⚡   | Баланс |
| small  | ~244 МБ | ⭐⭐⭐⭐ | ⚡⚡⚡    | Хорошо |
| **medium** | ~769 МБ | ⭐⭐⭐⭐⭐ | ⚡⚡ | **Рекомендуется** ✓ |
| large  | ~1550 МБ | ⭐⭐⭐⭐⭐ | ⚡ | Для мощных ПК |

### Установка

Whisper устанавливается автоматически через `pip install openai-whisper`.

Модель скачается автоматически при первом запуске приложения.

### Настройка

В файле `config.py`:
```python
DEFAULT_STT_MODEL = "medium"  # Измените на нужную модель
```

**Текущая настройка:** `medium` (лучший баланс качества и скорости)

## 2. Vosk - Потоковое распознавание

Используется для WebSocket streaming (распознавание в реальном времени).

### Доступные русские модели

| Модель | Размер | Качество | RAM | Рекомендация |
|--------|--------|----------|-----|--------------|
| vosk-model-small-ru-0.22 | 45 МБ | ⭐⭐⭐ | ~200 МБ | Быстрая работа |
| **vosk-model-ru-0.42** | 1.5 ГБ | ⭐⭐⭐⭐⭐ | ~2 ГБ | **Лучшее качество** ✓ |

### Установка Vosk модели

#### Шаг 1: Скачайте модель

**Рекомендуемая модель (лучшее качество):**
```bash
cd models/
curl -O https://alphacephei.com/vosk/models/vosk-model-ru-0.42.zip
unzip vosk-model-ru-0.42.zip
rm vosk-model-ru-0.42.zip
```

**Альтернатива (маленькая модель):**
```bash
cd models/
curl -O https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
unzip vosk-model-small-ru-0.22.zip
rm vosk-model-small-ru-0.22.zip
```

#### Шаг 2: Проверьте структуру

После распаковки должна быть такая структура:
```
blaBy/
└── models/
    └── vosk-model-ru-0.42/
        ├── am/
        ├── graph/
        ├── ivector/
        └── conf/
```

#### Шаг 3: Настройка в config.py

В файле `config.py`:
```python
VOSK_MODEL_PATH = BASE_DIR / "models" / "vosk-model-ru-0.42"
```

Если используете маленькую модель:
```python
VOSK_MODEL_PATH = BASE_DIR / "models" / "vosk-model-small-ru-0.22"
```

## Рекомендации

### Для максимального качества (текущая настройка)
- **Whisper:** medium
- **Vosk:** vosk-model-ru-0.42
- **Требования:** 4+ ГБ RAM, средний процессор

### Для быстрой работы на слабых ПК
- **Whisper:** base или small
- **Vosk:** vosk-model-small-ru-0.22
- **Требования:** 2+ ГБ RAM, любой процессор

### Для максимальной точности (мощные ПК)
- **Whisper:** large
- **Vosk:** vosk-model-ru-0.42
- **Требования:** 8+ ГБ RAM, мощный процессор/GPU

## Устранение проблем

### Ошибка: "Модель Vosk не найдена"

1. Проверьте, что модель скачана и распакована в `models/`
2. Проверьте путь в `config.py` → `VOSK_MODEL_PATH`
3. Убедитесь, что имя директории совпадает

### Whisper работает медленно

1. Попробуйте меньшую модель: `base` или `small`
2. Если есть NVIDIA GPU, установите `torch` с CUDA поддержкой
3. Проверьте, что `fp16=False` в `core/stt_module.py` (для CPU)

### Низкое качество распознавания

1. Используйте большую модель: `medium` или `large` для Whisper
2. Для Vosk используйте полную модель: `vosk-model-ru-0.42`
3. Проверьте качество микрофона и уровень шума
4. Говорите четко и не слишком быстро

## Дополнительные настройки

### Изменение языка распознавания

В коде при вызове распознавания:
```python
# Для английского
text = stt.transcribe(audio_path, language="en")

# Для русского (по умолчанию)
text = stt.transcribe(audio_path, language="ru")
```

### Автоматическое определение языка

Whisper может автоматически определять язык:
```python
result = model.transcribe(audio_path)  # без параметра language
detected_language = result["language"]
text = result["text"]
```
