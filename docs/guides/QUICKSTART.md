# Быстрый Старт - Развертывание Рефакторинга

## 🚀 Три простых шага для запуска

### Шаг 1: Развертывание (1 команда, 5 секунд)

```bash
./deploy_refactoring.sh
```

Скрипт автоматически:
- ✅ Создаст резервные копии
- ✅ Заменит main.py и index.html
- ✅ Выведет инструкции

### Шаг 2: Запуск (1 команда, 10 секунд)

```bash
python main.py
```

Ожидаемый вывод:
```
==================================================
Инициализация голосового ассистента...
==================================================
Все модули успешно загружены!
Сервер готов к работе
==================================================
INFO:     Uvicorn running on http://0.0.0.0:8000
```

### Шаг 3: Тестирование (2 минуты)

1. Откройте: http://localhost:8000
2. Нажмите F12 (консоль разработчика)
3. Проверьте:
   - [ ] Страница загрузилась
   - [ ] Нет ошибок в консоли
   - [ ] Список моделей загрузился

4. Нажмите "Начать диалог"
5. Скажите что-нибудь
6. Проверьте что:
   - [ ] Распознавание работает
   - [ ] Ответ генерируется
   - [ ] TTS воспроизводится
   - [ ] Минимум логов в консоли (только ошибки)

## ✅ Готово!

Если всё работает - рефакторинг успешен!

## 🔄 Откат (если что-то не так)

```bash
# Восстановите из резервной копии
ls -la backups/  # Найдите последнюю
cp backups/backup_TIMESTAMP/main.py main.py
cp backups/backup_TIMESTAMP/index.html static/index.html

# Перезапустите
python main.py
```
