# Git Workflow - Создание коммитов

## Создание коммита

### Базовый процесс создания коммита

1. **Добавьте изменения в индекс**:
   ```bash
   git add .
   ```
   Или добавьте конкретные файлы:
   ```bash
   git add file1.py file2.py
   ```

2. **Создайте коммит с префиксом "cursor"**:
   ```bash
   git commit -m "cursor: Ваше сообщение коммита здесь"
   ```

### Формат сообщения коммита

Всегда добавляйте префикс `cursor:`, затем пробел и ваше описательное сообщение.

**Хорошие примеры**:
- `cursor: Добавлена потоковая передача голоса`
- `cursor: Исправлена проблема с воспроизведением аудио в WebSocket обработчике`
- `cursor: Обновлена документация API`
- `cursor: Рефакторинг модуля управления состоянием`

**Плохие примеры**:
- `Добавлена потоковая передача голоса` (отсутствует префикс)
- `cursor:исправление` (отсутствует пробел после двоеточия)
- `Cursor: Добавлена функция` (неправильная капитализация)

### Шаги процесса

1. Внесите изменения в код
2. Просмотрите изменения: `git status` или `git diff`
3. Добавьте изменения в индекс: `git add <файлы>`
4. Создайте коммит с префиксом: `git commit -m "cursor: <описание>"`
5. Отправьте в удалённый репозиторий: `git push`

### Продвинутое использование

**Коммит с подробным сообщением**:
```bash
git commit -m "cursor: Добавлена функция X" -m "Подробное описание того, что было изменено и почему"
```

**Исправление предыдущего коммита** (если забыли добавить префикс):
```bash
git commit --amend -m "cursor: Ваше исправленное сообщение"
```

### Быстрая справка

```bash
# Просмотр статуса
git status

# Посмотреть изменения
git diff

# Добавить все изменения
git add .

# Создать коммит с префиксом cursor
git commit -m "cursor: Ваше сообщение"

# Отправить в удалённый репозиторий
git push
```
